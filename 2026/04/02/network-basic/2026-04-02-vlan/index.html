Posted on 2026-04-02 Edited on 2026-10-12 In network , vlan Views:

VLAN技术

1.0 VLAN 作用

  • VLAN(虚拟局域网技术)为以太网引入了灵活的控制手段

  • 解决了传统局域网交换机以下问题

    • 安全性差，各个端口之间可以直接互访
    • 效率低，例如广播问题，消耗带宽和CPU资源
    • 业务扩展能力差，设备平等对待每台主机的报文，无法实现差别服务

  • VLAN技术作用

    • 将用户终端分成多个逻辑的网络组 （VLAN 1 VLAN 2 …）
    • 组内可以通讯，组间不允许通讯
    • 二层转发的 单播 组播 广播 报文只能在组内转发
    • 很容易实现对组成员添加，删除

2.0 VLAN 通讯原理

  • 为实现转发控制，在待转发的以太网帧中添加VLAN标记（标记帧 tagged frame）

  • 设定交换机端口对该标记帧进行以下处理

    • 丢弃帧
    • 转发帧
    • 添加标记
    • 移除标记

  • 所有以太网帧在交换机中都以标记帧的形式流动

    • 即某端口从对端设备收到的帧有可能是 untagged frame（非标记帧）

    • 但从本交换机其他端口转发过来的帧一定是 tagged frame

    • 若收到 tagged frame 则进行转发

    • 若收到 untagged frame 则必须加标记 => (untagged => tagged)

  • VLAN 编号范围 04095 其中0和4095预留 实际:14094可用

3.0 VLAN 接口类型

  • Access 接口

    • 仅允许VLAN ID与接口的PVID相同数据帧通过
    • 接口收到设备发送帧为untagged，交换机强制对数据帧添加该接口的PVID
    • 接口发往对应主机的以太网帧永远是untagged
    • 多数交换机默认 接口类型是Access PVID = 1，VLAN 1由系统创建，不能被删除

  • Trunk 隧道接口类型 （用于连接交换机）

    • 交换机之间传输标记帧，可自由设定允许通过多个VLAN ID ID可以与PVID相同，也可不同
    • 若标记帧的VLAN ID 未配置，则丢弃帧
