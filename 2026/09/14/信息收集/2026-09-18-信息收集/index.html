1.6 真实IP收集

如何判断网站使用了CDN?

  1. 多地Ping: 若IP结果不唯一, 则使用了CDN

  2. DNS解析: 返回多个IP

  3. HTTP响应头分析: 使用 curl -I 查看响应头, 出现 Server: cloudflare, X-Cache 等字段

如何绕过CDN?

  1. 很多网站只对主站或者高流量子站做CDN, 若使用真实IP的子站和主站处于同一个服务器或者C段, 则可通过子站IP辅助查找主站真实IP

  2. 历史DNS记录

  3. 国外访问

  4. 邮箱服务: 查看邮件头 Received 字段

1.7 端口信息收集

目标: 在存活资产基础上发现开放端口, 为服务识别和 Web 入口扩展做准备
原则: 先快后慢, 先全后精, 控制速率

扫描策略:

  • 先对存活 IP 做常见端口快速扫描
  • 再对重点 IP 做全端口扫描
  • 最后用 nmap 对开放端口做精细识别
  • CDN/WAF 资产先尝试找真实 IP, 再扫端口
  • 非标端口发现后, 重新用 httpx 探测 Web 服务

常用工具:

naabu: 快速对全端口进行扫描

nmap 精细识别
