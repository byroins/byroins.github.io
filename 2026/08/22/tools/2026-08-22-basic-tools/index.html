1.0 uv管理Python

1.1 为什么选择uv?

  • 极速: Rust内核, 比传统pip快10倍以上
  • 多版本切换平滑
  • 强隔离性, 项目环境独立
  • 兼容性: 完全兼容pip
  • 跨平台: Linux / macOS / Windows
