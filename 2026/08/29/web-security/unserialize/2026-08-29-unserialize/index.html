1.0 PHP 反序列化

1.1 基础

序列化是将内存中的对象转换为字节序列或字符串的过程, 以便于存储, 传输或在网络传递.

反序列化则是将字节序列或字符串还原为原始对象.

漏洞原理: 反序列化漏洞的本质: 攻击者可控的恶意数据被程序信任并还原为对象, 而程序未对输入进行严格验证.

03 进阶案例

  • 反序列化特性:
    • 反序列化生成的对象, 成员属性值由被反序列化的字符串决定, 与原来类预定义的值无关
    • 反序列化使用unserialize() 将字符串转换为对象, 序列化使用serialize() 将对象转化为字符串
    • 反序列化不触发类的成员方法, 需要调用方法后才能触发

PHP 对象序列化后的字符串

每个属性定义为: 数据类型:长度:值

源码分析: 对于public protected private:

  • public
    • 格式: s:属性长度:"属性名";值类型:值长度:"值";
    • 无前缀和空字节
  • protected
    • 格式:s:属性长度:"\0*\0属性名";值类型:值长度:"值";
    • 属性名前加\0*\0 [空字节][*]
      • 第一个\0表示protected
      • *是字面量星号
      • 第二个\0分隔符
  • private
    • 格式: s:属性长度:"\0类名\0属性名";值类型:值长度:"值";
    • 属性名前加 \0类名\0 即: [空字节] + [所属类名] + [空字节]

注意: 在 URL/HTTP 请求中传递时, 需将空字节写为 %00
